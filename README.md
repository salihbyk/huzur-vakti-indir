# Huzur Vakti

Namaz vakitleri, ezan, Kur'an okuma ve hatim takibi için Android uygulaması.

## Kurulum

1. Telefonda şu linke dokun: [Huzur Vakti'yi indir](https://github.com/salihbyk/huzur-vakti-indir/releases/latest/download/Huzur-Vakti.apk)
2. İndirme bitince dosyayı aç.
3. Telefon "bilinmeyen uygulamalar" için izin isterse **Ayarlar → Bu kaynaktan izin ver** de ve geri dön.
4. **Yükle** (daha önce kuruluysa **Güncelle**) düğmesine bas.

Güncellemeler aynı linkten iner; hatim ilerlemesi ve ayarlar korunur.
